# ClarisImpact ファイル形式の覚え書き

サンプルファイルの観察と、元のアプリでの表示との比較から推定した内容です。
数値はすべてビッグエンディアンです（Windows 版の制御語だけはリトルエンディアン）。
「推定」と書いた項目は、サンプルの範囲でしか確かめていません。

## 1. ファイルの先頭

| オフセット | 内容 |
| --- | --- |
| 0 | 形式の版。1 = Mac 版 1.0、2 = Windows 版 2.0 の文書、3 = 2.0 のスタイル |
| 4–7 | `CIPT`（文書）または `BOBO`（スタイル・ライブラリ。ClarisWorks のクリエータと同じ） |

Mac のファイルタイプは次のとおりです。

| タイプ | 文書の種類 |
| --- | --- |
| `iDrw` | 図 |
| `iRpt` | レポート |
| `iPrs` | プレゼンテーション |
| `iLib` | ライブラリ |
| `iSty` | スタイル |

## 2. Windows 版の圧縮

先頭8バイトの後ろは、次の構造になっています。

```
u32  展開後のチャンク長（0x5000）
繰り返し:
  u32  n（このチャンクの残りバイト数）
  u32  0
  n-4  LZ データ
```

LZ データの読み方は次のとおりです。

- 16ビットの制御語（**リトルエンディアン**）を読み、下位ビットから16個の要素を順に処理します。
- ビットが 0 の要素は、生のバイト1つです。
- ビットが 1 の要素は、2バイトの参照 `b1 b2` です。長さは `(b1 & 0x0F) + 1`、距離は `b2 | (b1 & 0xF0) << 4` です。
- チャンクごとに独立して、0x5000 バイトに展開されます。

展開後は Mac 版と同じ構造になります。

## 3. ヘッダ内のリスト構造

`size(4) n(2) -1(2) 0(2) dataSize(2) headerSize(2) ?(2) header data…` という形の汎用リストが並んでいます。
データサイズで見分けられるものは次のとおりです。

| dataSize | 内容 |
| --- | --- |
| 6（256件） | カラーパレット（16ビット RGB） |
| 96 | 段落ルーラー：使用数, フラグ, 字下げ×3, …。フラグの上位2ビットが配置（0 左、1 中央、2 右、3 両端）、0x0008 が箇条書き |
| 38 | 文字スタイル：フォント(2) フラグ(2) サイズ(1) 色(1) 名前(Pascal) |
| 40（ヘッダ64） | グラデーション：RGB×4, 色数(1), 種類(1), 角度(2) |
| 264 | レイヤー／スライド：名前(Pascal) …（残りは未使用領域を含む） |
| 72（`FNTM` 付き、2.0） | フォント表：番号(2) … オフセット8 に名前(Pascal) |

## 4. DSET ゾーン

```
'DSET' size(4) numData(2) -1(2) 0(2) dataSize(2) headerSize(2) flags(2) [fileType(1) ?] id(2) …
```

- fileType：0 = 図形グループ、1 = テキスト、2 = 表。
- グループの場合、ゾーンの末尾に 56 バイトの図形レコードが numData 個並びます。
- ゾーンの直後に長さ付きブロック（`u32 len` + データ）が続きます。

### 図形レコード（56バイト）

| オフセット | 内容 |
| --- | --- |
| 0 | 種類（下表） |
| 2 | フラグ：0x40 / 0x80 = 回転可能（枠が余白付き）、0x10 = グラデーション、0x0A = ページ枠 |
| 3 | 副フラグ：0x12 両方 = 影、0x80 = 塗りなし（推定） |
| 4–19 | 枠 y0, x0, y1, x1（24.8 固定小数点） |
| 20–21 | 線幅（整数部, 1/256 単位） |
| 22, 23 | 線の色, 塗りの色（パレット番号） |
| 24, 25 | 線のパターン, 塗りのパターン（グラデーション時は 2 + 表の番号） |
| 34–37 | 子ゾーンの番号（種類1）/ 角度（種類2、16.16 固定小数点のラジアン）/ 角丸の直径（種類4） |
| 38–41 | 角丸の縦の直径（種類4）。種類2では値 3 のとき矢じりが始点側 |
| 46–47 | 1 = メモ、2 = 隠す（閉じたメモ、グラフのデータ表） |

| 種類 | 意味 |
| --- | --- |
| 0 | モデルの記述子（描画しない） |
| 1 | 子ゾーンへの参照（グループ／テキスト／表） |
| 2 | 線・矢印：枠は線の外接矩形に余白を足したもの。角度は始点→終点の向き（y 下向き） |
| 3 | 四角 |
| 4 | 角丸四角 |
| 5 | 楕円 |
| 7 | 組織図のコネクタ（折れ線） |
| 8 | ベジェ曲線：データブロック（26バイト×点数：アンカー, 制御点1, 制御点2, フラグ） |
| 10 | 画像（PICT ブロック） |
| 11 | グラフ・ガント等のモデル（PICT のプレビューを持つ） |

回転可能なグループ（フラグ 0x40 / 0x80）の枠は、中身の範囲に各辺同じ余白を足したものです。
子ゾーンの原点は、中身の範囲から逆算します。

### テキストゾーン

DSET の +24 から、`?(2) 親(2) 文字数(4) 本文ブロック数(2) 段落数(2) 書式数(2)` が並びます。
後続ブロックは次の順です。

```
段落 PLC（1.0: 8 バイト、2.0: 12 バイト）
文字書式（1.0: 位置4 フォント2 フラグ2 サイズ1 色1 / 2.0: サイズと色が各2バイト）
トークン
サイズ
本文 × 本文ブロック数
```

### 表（CTAB）

ブロックの先頭に `?(6) 'CTAB' 最大列番号(2) 最大行番号(2)` があります。
その後に、列ごとに `'COLM'` と `'CHNK'`（652バイト）の組が続きます。

- CHNK の +12 から、行ごとのセル位置（CHNK からの相対、0 は空のセル）が並びます。
- セルは `種別, ?, フォント(2), サイズ, フラグ, 文字色, 配置, 背景色, ?, Pascal 文字列` です。
- 列幅と行の高さは、後続の 20 バイトのリスト 2 つにあります（推定）。

## 5. ページとスライド

- 先頭のオブジェクトがページ枠（種類1、フラグ 0x0A）になっているグループが、1枚のページです。
- 図形を持つページが複数あればプレゼンテーションです。
- ページ枠の中にだけ図形を持つページはマスタースライドで、各スライドの背景に重ねます。
- スライドの順番を記録している場所は、まだ特定できていません。
