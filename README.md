# Impact Reader

ClarisImpact（1994〜1996年、Claris Corporation）の文書をブラウザで表示するビューアです。
ファイルはブラウザの中だけで読み込み、どこにも送信しません。

## できること

| 文書 | 対応状況 |
| --- | --- |
| Mac 版 1.0 の図（ドローイング） | テキスト、矢印線、四角・角丸・楕円、ベジェ曲線、組織図のコネクタ、影、PICT 画像、閉じたメモのアイコン |
| Mac 版 1.0 のプレゼンテーション | スライドの一覧と切り替え、マスタースライドの重ね描き、グラデーション、箇条書き、表、グラフ・ガントチャート・カレンダー（保存されているプレビュー画像を使用） |
| Windows 版 2.0 の文書（`.CID` `.CIT` など） | LZ 圧縮の展開。展開後は Mac 版と同じ形式として表示。フォント名の表（FNTM）にも対応 |
| スタイル・ライブラリ（`BOBO` 署名のファイル） | 中の図形を表示 |

そのほか、次の機能があります。

- 表示倍率の変更（ページに合わせる、幅に合わせる、25〜600%）
- スライドの前後移動（← →、PageUp / PageDown）
- SVG と PNG での書き出し
- 構造パネル（ゾーンと図形の一覧、使用フォント）

## 使い方

```sh
npm install
npm run dev        # http://localhost:5199 で開く
npm run build      # dist/ に静的ファイルを出力（どこにでも置けます）
npm test           # 単体テスト（samples/ があれば回帰テストも）
```

画面に ClarisImpact のファイルをドロップするか、「ファイルを開く」から選びます。

開発用の補助として、次のものがあります。

- `node scripts/inspect.ts <ファイル> [ゾーン番号] [--raw]`：ファイルの構造を一覧表示します（Node 22.6 以降）。
- `dev/render.html?file=samples/...&root=<ゾーン番号>`：任意のゾーンを等倍で描画します（`npm run dev` 中のみ）。
- `?sample=<samples からの相対パス>` を付けて開くと、開発サーバーでサンプルを直接読み込みます。

## 構成

```
src/core/BinaryReader.ts   バイト列の読み取り、MacRoman / Windows-1252 の変換
src/impact/decompress.ts   Windows 版の LZ 圧縮の展開
src/impact/parser.ts       DSET ゾーン、図形レコード、テキスト、表、パレット、ルーラー、グラデーション
src/impact/pages.ts        図かプレゼンかの判定、スライドとマスターの検出
src/render/svg.ts          SVG への描画
src/render/textLayout.ts   折り返しと行の配置
src/render/fonts.ts        Mac のフォント番号やフォント名から Web フォントへの対応
src/pict/                  QuickDraw PICT（v1/v2）のデコードと canvas への描画
src/app/                   画面（TypeScript のみ、フレームワークなし）
docs/format.md             解析した形式の覚え書き
```

## 既知の制限

- **スライドの順番**：ファイル内の順番で並べています。順番を記録している場所がまだ特定できていないため、元のアプリとは順番が違うことがあります（サンプルでは「ClarisImpact」のスライドが2枚目に来ます）。
- **文字の配置**：元の Mac のビットマップフォントとは文字幅が違います。そのため、折り返し位置が元と異なることがあります。Bitstream 系のフォント（Bodoni BT など）は似た書体で代用しています。
- **Windows 版 2.0 の表**：セルの読み取りは 1.0 形式の表だけに対応しています。2.0 形式の表（タイムラインの作業名など）は空になります。
- **プレビュー画像がない図**：グラフやカレンダーなどのモデルは、ファイル内のプレビュー画像で表示しています。プレビュー画像がない場合は表示できません。モデルの記述子（種類 0）そのものはまだ解釈していません。
- **メモ**：閉じたメモはアイコンだけを表示します。
- **レポート文書**：本文が空のサンプルしかないため、本文の流し込みは未検証です。

## 互換性の検証方法

元のアプリの画面と比較して確認しました。

- Infinite Mac（Mac OS 8.1 のエミュレータ）で ClarisImpact 1.0 と 2.0 の体験版を動かし、同じファイルを開いた画面を撮影しました。
- その画像と、このビューアの描画結果を見比べています。

## 法的な位置づけについて

形式の解析は、文書ファイルを観察する方法（ブラックボックス解析）で行い、アプリ本体の逆アセンブルはしていません。
ClarisWorks 系の共通構造（DSET ゾーンなど）を把握するために、オープンソースの
[libmwaw](https://sourceforge.net/projects/libmwaw/)（MPL 2.0 / LGPL 2.1+）のソースを参考にしましたが、コードは流用していません。
「ClarisImpact」「Claris」は各権利者の商標です。このソフトウェアは Claris International Inc. とは関係ありません。
`samples/` のファイルは当時の体験版 CD-ROM から取得したもので、著作権は各権利者にあります。そのためリポジトリには含めていません。
